# MED — реестр источников и документов

## Статусы
- **connected** — адаптер реализован в репозитории; не гарантирует сетевую доступность на конкретном сервере.
- **candidate** — официальный источник установлен, но адаптер не реализован.
- **validated** — прошёл отдельную проверку схемы, доступности, полноты и воспроизводимости на выбранном стенде.

| ID | Документ / API | Содержимое | Статус | Что требуется |
|---|---|---|---|---|
| pubmed | NCBI PubMed E-utilities | Названия статей, авторы, журналы, даты, PMID, URL | connected | Проверить стабильность, квоты, полноту извлечения |
| clinicaltrials | ClinicalTrials.gov API v2 | Метаданные исследований, статусы и идентификаторы NCT | candidate | Написать и проверить адаптер |
| icd11 | WHO ICD API v2 | Диагностическая классификация ICD-11 | candidate | Учетная запись, OAuth credentials, лицензия, локализация |
| local_protocols | Локальные клинические протоколы | Нормативные документы / версии / области применимости | requires_source | Пользователь должен предоставить ссылки и юрисдикцию |

## Первичные официальные документы
1. NCBI E-utilities usage guidelines: https://eutilities.github.io/site/API_Key/usageandkey/ — не более 3 запросов/с без ключа.
2. PubMed E-utilities: https://www.ncbi.nlm.nih.gov/books/NBK25501/
3. ClinicalTrials.gov API: https://clinicaltrials.gov/data-api/api
4. WHO ICD API: https://icd.who.int/docs/icd-api/APIDoc-Version2/ — OAuth 2, API-Version: v2.
5. ICD-11 reference: https://icd.who.int/en/

## Правило источника
Для каждой записи MED фиксирует: `source_id`, исходный идентификатор и URL, дату публикации, дату получения, версию адаптера, область применения, статус проверки и контрольную сумму. Публикация, клиническое испытание, диагностический классификатор и клиническая рекомендация имеют разные уровни доказательности — MED не смешивает их автоматически.

Данные пациента, выписки, результаты лаборатории и другая медицинская информация не входят в текущий контур. Для них требуется отдельная согласованная модель хранения и политики доступа.
