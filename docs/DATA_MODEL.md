# MED — модель данных

Конвейер: SOURCE → FETCH → VALIDATE → NORMALIZE → TRACE → CALCULATE → REPORT.

Планируемые сущности (ещё не созданные таблицы):
- sources: идентификатор, провайдер, статус, дата проверки.
- documents: внешний ID, заголовок, URL, дата публикации, дата извлечения, источник.
- document_versions: версия документа, checksum, версия парсера.
- clinical_concepts: код классификатора, редакция, определение, документ-источник.
- calculation_runs: идентификатор запуска, версия правил, hash входа и выхода.
- calculation_evidence: связь расчёта с документом и статус подтверждения.

Проверки: воспроизводимость результатов, сохранение происхождения каждого документа, разделение статусов candidate / connected / validated. Поиск исследований не равнозначен клинической диагностике.
