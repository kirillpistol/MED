# MED — план развития

1. Проверить официальные источники и условия использования.
2. Подключить ClinicalTrials.gov API с фикстурами и тестами.
3. Создать собственное хранилище метаданных и миграции.
4. Подключить справочник ICD-11 после согласования доступа и редакции.
5. Определить медицинские показатели и расчётные формулы, проверить их на эталонных случаях с профильными специалистами.
6. Создать воспроизводимые отчёты с источниками, датами, версиями и оценкой неопределённости.
7. Протестировать MED на отдельном контейнере, затем планировать интеграцию с GENESIS.

Нужно уточнить: юрисдикцию клинических документов и первое направление диагностики.
