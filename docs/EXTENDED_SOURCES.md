# MED — расширенный каталог источников

Полученный список из 17 ресурсов систематизирован в `config/extended_sources.json`. Это **кандидаты**: они ещё не подключены к фоновому сборщику, не проверены на доступность на VPS и не утверждены для использования в медицинских расчётах. Текущие работающие в коде адаптеры PubMed и ClinicalTrials.gov перечислены отдельно в `config/sources.json`.

## Группы источников

| Группа | Ресурсы | Следующий шаг |
|---|---|---|
| РФ / справочники | НСИ Минздрава, data.gov.ru, ЕМИСС, SibMed, БиоВитрина, реестр медизделий, ГРЛС | Проверка регламента, аутентификации, лицензий, выгрузки и словарей |
| Регенерация | PRIDE, NCBI GEO, HCA Azul | Проверка схем метаданных, выбранных наборов и размера файлов |
| Биопринтинг | bioprinting-ai-mining-framework, AI_embedded-bioprinting, hydrogel | Аудит зависимостей, лицензий, воспроизводимости и наличия исходных данных |
| Нейротехнологии | DANDI, NEMAR, OpenNeuro, EEGDash | Валидация форматов NWB/BIDS, условий доступа и полномочий на использование |

Первичные официальные страницы:
- [Human Cell Atlas API](https://data.humancellatlas.org/apis)
- [DANDI REST API](https://docs.dandiarchive.org/api/rest-api/)
- [PRIDE Archive API](https://pride-archive.github.io/PrideAPIDocs/introduction.html)
- [NCBI E-utilities](https://www.ncbi.nlm.nih.gov/books/NBK25501/)

## Стандарт подключения

1. Проверить, что источник доступен, документация актуальна и разрешено выбранное использование.
2. Сохранить пример ответа, условия доступа, версию схемы, дату проверки.
3. Реализовать отдельный адаптер с ограничениями размера, времени и частоты запросов.
4. Написать тесты на фикстурах и ошибки сетевого взаимодействия.
5. Нормализовать метаданные с ID источника, URL, временем получения, контрольной суммой и версией адаптера.
6. Разрешать регулярный сбор только после прохождения проверки. Не исполнять сторонние GitHub-проекты на сервере без аудита кода.

Система не делает медицинских выводов из простого факта наличия записи. Наборы, описанные как деидентифицированные, требуют самостоятельной проверки условий использования и риска повторной идентификации.
